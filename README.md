# Покер · совет

Подсказчик для техасского холдема на iPhone: стол на 9 мест, позиция, твои карты,
шанс выиграть и совет на каждой улице. Работает без интернета, всё считается в телефоне.

Для тренировки и разбора раздач после игры (в клубах и онлайн-румах подсказки во время игры запрещены).

Запуск у себя: `python3 -m http.server 8091` → http://localhost:8091 · Тесты: `npm test`
