КАК ПОСЧИТАТЬ ФЛОПЫ НА СВОЁМ КОМПЬЮТЕРЕ

1. Скачай с ОФИЦИАЛЬНОЙ страницы https://github.com/bupticybee/TexasSolver/releases
   файл TexasSolver-v0.2.0-Windows.zip и распакуй (например, на Рабочий стол).
   Появится папка TexasSolver-v0.2.0-Windows (внутри console_solver.exe).
2. Эту папку poker положи ВНУТРЬ папки TexasSolver-v0.2.0-Windows.
3. Перед сном закрой тяжёлые программы (игры, много вкладок) и дважды щёлкни run.bat.
   Если Windows скажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
   Окно не закрывай, компьютер не выключай и не отправляй в сон до утра.
4. Утром, когда в окне написано «ВСЁ», перетащи папку results в VS Code
   в /root/poker-bot/data-build/solver/pc-flops/poker/ и напиши Claude «флопы готовы».

Память (примерно 5 ГБ) занята только пока идёт расчёт. Закрыл окно — всё освободилось.
Если не успело всё за ночь — не страшно: запусти run.bat ещё раз, готовые он пропустит.
